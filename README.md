# AV Flow CRM

**AV significa Acelera Vendas.**

CRM SaaS multiempresa para atendimento oficial pelo WhatsApp Business Platform, qualificação de leads, acompanhamento de campanhas e gestão comercial.

## Identificadores do projeto

- Repositório recomendado no GitHub: `av-flow-crm`
- Pacote npm: `av-flow-crm`
- Cloudflare Worker: `av-flow-crm`
- Cloudflare D1: `av-flow-crm-db`

Consulte `docs/ARCHITECTURE.md` para a arquitetura e `docs/DEPLOYMENT.md` para provisionamento e implantação.
